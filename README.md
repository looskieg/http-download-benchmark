# HTTP Download Benchmark

Консольный скрипт выполняет 10 последовательных скачиваний по одному URL. Каждое скачивание начинается с GET-запроса и включает чтение тела ответа блоками по 64 КиБ без сохранения на диск. При перенаправлении одно скачивание может включать несколько GET-запросов.

## Запуск

Нужен Python 3.10 или новее. Все зависимости входят в стандартную библиотеку.

```sh
python benchmark.py "<URL файла>"
```

Для локальной проверки запустите в папке проекта `python -m http.server 8000 --bind 127.0.0.1`. Во втором терминале из той же папки выполните:

```sh
python benchmark.py "http://127.0.0.1:8000/README.md"
```

## Результат

```text
Average request time: 0.250000 s
Total downloaded: 10485760 bytes
Download speed: 4.000 MiB/s
```

- **Среднее время запроса** в секундах — сумма длительностей, делённая на 10. Время каждого запроса измеряется от начала GET до конца чтения тела и включает ожидание ответа и обработку перенаправлений.
- **Общий объём** в байтах — сумма фактически прочитанных байтов тела десяти ответов.
- **Скорость** в МиБ/с — общий объём в байтах, делённый на 1 048 576 и на сумму длительностей в секундах. Один МиБ равен 1 048 576 байтам.

Таймаут блокирующих сетевых операций — 30 секунд. При первой ошибке запроса скрипт пишет её причину и номер запроса в `stderr` и возвращает код `1`. Итоговые метрики выводятся после десяти успешных запросов. Некорректные аргументы дают код `2`.
