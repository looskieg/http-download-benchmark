# HTTP Download Benchmark

Консольный скрипт выполняет 10 последовательных скачиваний по одному URL. Каждое скачивание начинается с GET-запроса и включает чтение тела ответа блоками до 64 КиБ без сохранения на диск. При перенаправлении одно скачивание может включать несколько GET-запросов.

## Запуск

Нужен Python 3.10 или новее. Все зависимости входят в стандартную библиотеку.

```sh
python benchmark.py "<URL файла>"
```

Для локальной проверки запустите в папке проекта `python -m http.server 8000 --bind 127.0.0.1`. Во втором терминале из той же папки выполните:

```sh
python benchmark.py "http://127.0.0.1:8000/README.md"
```

## Результат

В терминале прогресс-бар показывает число завершённых скачиваний, номер текущего запроса и объём полученных данных. При известном размере ответа он также показывает процент скачивания. Прогресс пишется в `stderr`, а итоговые метрики — в `stdout`. При перенаправлении `stderr` в файл скрипт пишет по строке на запрос и одну строку по завершении замера.

```text
Average request time: 0.250000 s
Total downloaded: 10485760 bytes
Download speed: 4.000 MiB/s
```

- **Среднее время запроса** в секундах — сумма длительностей, делённая на 10. Время каждого запроса измеряется от начала GET до конца чтения тела и включает ожидание ответа, обработку перенаправлений и обновление прогресс-бара в терминале.
- **Общий объём** в байтах — сумма фактически прочитанных байтов тела десяти ответов.
- **Скорость** в МиБ/с — общий объём в байтах, делённый на 1 048 576 и на сумму длительностей в секундах. Один МиБ равен 1 048 576 байтам.

Таймаут отдельной операции сокета, например попытки подключения или чтения данных, — 30 секунд. Для DNS действуют системные настройки. Общего лимита для одного скачивания или всей серии скрипт не задаёт. Например, большой файл может скачиваться дольше 30 секунд, если данные продолжают поступать. Остановить замер можно сочетанием `Ctrl+C`.

При первой ошибке запроса скрипт пишет её причину и номер запроса в `stderr` и возвращает код `1`. Итоговые метрики выводятся после десяти успешных запросов. Некорректные аргументы дают код `2`.
